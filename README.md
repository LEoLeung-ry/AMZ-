# Amazon 全球类目机会与经营准入系统 V3.1

独立测试版，支持日本、美国、德国、英国四站点。

## 这次新增

- 将原“可进入性”明确为**竞争可进入性**
- 新增独立的**经营准入门槛**：A普通可进入、B有条件、C高门槛、D默认排除
- 对食品、补充剂、酒类、药品、宠物药/农药、医疗器械、化妆品、电池、电气、儿童用品等做多语言规则识别
- 新增经营者画像和能力开关
- 新增公司适配度、跨境友好度、所需资源、拦截原因和准入判断置信度
- 最终优先级 = 市场机会分 × 准入系数 × 公司适配度
- 主榜默认只显示A/B；C/D保留在“准入研究”页
- 同时显示本位币和人民币折算；趋势仍使用本位币，避免汇率造成假增长
- 默认人民币比较汇率采用 2026-07-27 ECB 欧元参考汇率交叉折算，可在页面侧边栏覆盖

## 原有能力

- 自动识别不同列顺序、表头位置和字段别名
- 类目ID科学计数法安全恢复
- 四站点货币与根类目标准化
- 市场、需求、竞争可进入性、变现、流量效率、痛点、数据置信度七因子
- 大单品、蓝海、高客单、结构性需求、稳健、自定义权重
- 全站排名 + 同大类内部排名混合
- 多维机会矩阵、跨站点比较、单类目诊断、数据质量中心
- 多快照趋势接口；当前只有单快照时不伪造时间趋势

## 运行

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

## 重要说明

经营准入规则是商业筛选和风险提示，不构成法律或监管意见。任何C/D类目，以及涉及药品、食品、酒类、农药、医疗器械、儿童安全、电池危险品的产品，都必须由目标国专业机构和平台后台进一步确认。
