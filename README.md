# Amazon 全球类目机会与趋势发现系统 V3

独立测试版，支持日本、美国、德国、英国四站点。

## 核心能力

- 自动识别不同列顺序、表头位置和字段别名
- 类目ID科学计数法安全恢复
- 四站点货币与根类目标准化
- 市场、需求、竞争可进入性、变现、流量效率、痛点、数据置信度七因子模型
- 大单品、蓝海、高客单、结构性需求、稳健、自定义权重
- 全站排名 + 同大类内部排名混合
- 多维机会矩阵
- 跨站点关键词候选比较
- 单类目规则化诊断
- 数据质量与异常追踪
- 多快照趋势计算接口；当前公开源只有单快照时不伪造趋势

## 运行

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

## 部署原则

先在 `multisite-v3-beta` 分支和独立测试应用验证，不覆盖现有生产站点。
