# V3.1 经营准入与人民币比较层

## 经营逻辑

- 市场机会分回答：市场是否有吸引力。
- 经营准入回答：普通跨境卖家是否具备合法、稳定进入条件。
- 公司适配回答：当前供应链和组织能力是否匹配。
- 最终优先级 = 市场机会分 × 准入系数 × 公司适配度。

## 准入等级

- A：普通可进入
- B：有条件可进入
- C：高门槛，默认进入受监管研究页
- D：默认排除

主榜默认只显示 A/B。用户主动修改筛选时仍可研究 C/D，但系统不会将其伪装为普通蓝海。

## 人民币比较

保留本位币，同时提供人民币销售额、均价和单 ASIN 收入。默认使用 2026-07-27 ECB 欧元参考汇率交叉折算，侧边栏可改为公司固定经营汇率。真实时间趋势始终使用本位币，避免汇率变化制造假增长。
